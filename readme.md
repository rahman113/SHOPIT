# 🛒 ShopIT - E-Commerce Platform

ShopIT is a full-stack MERN (MongoDB, Express.js, React, Node.js) e-commerce application featuring authentication, product catalog management, shopping cart functionality, payment integration, and an admin dashboard.

---

## Features

- **User Authentication:** Login, registration, password reset, and role-based access control (User/Admin).
- **Product Management:** Search, filter by price/category, rating displays, and detailed product views.
- **Shopping Cart & Checkout:** Cart persistence, shipping details form, order summaries, and payment processing via Stripe.
- **Responsive UI:** Modern design with glassmorphism styling, clean micro-interactions, and mobile responsiveness.
- **Admin Dashboard:** Manage products, orders, and user accounts.

---

##  Tech Stack

- **Frontend:** React, Redux, React Router v5, Bootstrap 5 / Custom CSS
- **Backend:** Node.js, Express.js, MongoDB (Mongoose)
- **Authentication:** JWT (JSON Web Tokens), Cookies
- **Payments:** Stripe API
- **State Management:** Redux
