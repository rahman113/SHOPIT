# ShopIT - Full Stack E-Commerce Application

ShopIT is a modern, responsive e-commerce platform built with React, Redux, Node.js, Express, and MongoDB. It features a complete shopping flow including user authentication, product search, shopping cart management, order processing, and payment integration.

---

## Features

- **User Authentication**: Secure Login, Registration, Password Reset, and Profile Management.
- **Product Management**: Browse products, search by keyword, filter by categories, and view detailed product pages with reviews and ratings.
- **Shopping Cart**: Add/remove items, update quantities, and view live cart counts in the navigation header.
- **Sticky Navigation Bar**: Sticky header with quick access to search, user profile, and cart status.
- **Payment Integration**: Stripe payment gateway integration for secure checkout.
- **Admin Dashboard**: Manage products, orders, users, and product reviews.
- **Responsive Layout**: Designed using Bootstrap and custom CSS for seamless multi-device usage.

---

## Tech Stack

- **Frontend**: React.js, Redux, Bootstrap, CSS3, FontAwesome
- **Backend**: Node.js, Express.js
- **Database**: MongoDB (Mongoose ODM)
- **State Management**: Redux, Redux Thunk
- **Authentication**: JWT (JSON Web Tokens)
- **Payment Gateway**: Stripe API
